# VCF 9.1 Import Brownfield Environment - Precheck

此 Repo 記錄將舊有 vSphere 環境（Brownfield）Import 至 VCF 9.1 的 Precheck 流程與步驟。

## 適用情境
- 現有 vSphere 8.0 Update 3a 以上環境
- Import 為 VCF Workload (VI) Domain

## 目錄
- `docs/precheck-checklist.md` - Precheck 檢查項目清單
- `docs/import-procedure.md` - Import 完整操作步驟
- `scripts/run-precheck.sh` - Precheck 腳本指令
